Find the barriers your users hit.

Scan a page's HTML for common accessibility problems — missing alt text, unlabeled fields, heading order, colour contrast and unnamed buttons — grouped by severity.


Automated checks catch common problems only. A manual audit with a screen reader and keyboard is still necessary.

How it works

Paste a page's HTML and click Scan. It checks alt text, labels, heading order, unnamed buttons/links and inline colour contrast, grouped by severity. Automated checks never replace a manual audit — the report says so.

Data is stored only in your browser (localStorage) unless a feature explicitly fetches a URL or API you enter. Run npm start for the real server — live checks run server-side and history is saved on disk. Opening index.html directly still works in browser-only mode.
